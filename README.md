## Photography Business Website

> **Web Design · Front-End Development · Collaborative Project**

A multi-page website designed and developed with a classmate for a mock photography business as part of a school project.

Our goal was to move beyond a basic business website and create a **modern, seamless user experience** that made it easy for potential clients to explore the business and get in touch. The site incorporates multiple pages and communication options to make navigation and client interaction feel intuitive.

**Highlights**

* Designed a clean and modern user interface
* Built a multi-page website structure
* Added multiple methods for users to communicate with the business
* Collaborated on both the design and development process
* Focused on creating a cohesive experience across the site

## RecipeShare

> **Full-Stack Web Development · PostgreSQL · Authentication**

A database-backed recipe-sharing platform developed alongside my class as part of a semester-long project.

RecipeShare was designed to create a **convenient online community for discovering and sharing recipes**. Users can create an account, log in, contribute their own recipes, and rate recipes shared by others. The application uses **PostgreSQL** for persistent data storage and authentication to support individual user accounts.

**Highlights**

* PostgreSQL database integration
* User registration and login authentication
* Recipe creation and storage
* Recipe rating functionality
* Database-backed user and recipe data
* Community-focused application design
